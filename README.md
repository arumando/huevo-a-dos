# Huevo a Dos

Juego cooperativo para dos personas: cada quien controla un pájaro y entre los dos cargan un huevo frágil con una cuerda hasta el nido.

- Abre la página, toca **Crear sala** y manda el enlace a tu pareja. Al abrirlo entra directo a tu sala.
- Arrastra el dedo en cualquier parte de la pantalla para mover tu pájaro.
- También se puede jugar en un solo teléfono (un dedo de cada lado).

Todo el juego está en `index.html`. La conexión en vivo usa un servidor MQTT público (EMQX, con HiveMQ de respaldo).
